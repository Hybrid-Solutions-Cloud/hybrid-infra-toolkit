# Project context

<!-- Durable knowledge about what this project is and how it fits the wider estate. Rarely changes. -->

Hybrid Infrastructure Toolkit is the public HCS Core repository for repeatable hybrid infrastructure labs, reference environments, and demo operations. Its canonical GitHub repository is `Hybrid-Solutions-Cloud/hybrid-infra-toolkit`; the archived `ThisIsMyDemo/hybrid-infra-toolkit` repository is the historical source record. Public documentation is built with VitePress and served at `https://labs.hybridsolutions.cloud/hybrid-infra-toolkit/` through the GitHub Pages origin.

The repository contains PowerShell, Bicep, compiled ARM JSON, GitHub Actions, and Hyper-V cluster-lab documentation. GitHub OIDC subjects and self-hosted runner registration defaults intentionally target `Hybrid-Solutions-Cloud/hybrid-infra-toolkit`.
